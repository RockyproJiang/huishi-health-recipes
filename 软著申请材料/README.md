## 三、敏感信息处理（重要）

原源码中硬编码的敏感信息已全部清除，改为从**环境变量**读取，提交的源程序不含任何真实密钥：

| 原位置 | 已清除内容 | 现处理方式 |
|---|---|---|
| `config.py` | AI 接口 API Key、AI 网关地址、数据库口令、Flask 会话密钥 | 改为环境变量 `AI_API_KEY / AI_BASE_URL / DB_PASSWORD / FLASK_SECRET_KEY` 等读取 |
| `routes/health.py` | 舌诊分析 APPCODE、第三方图床 Key、第三方接口地址 | 改为环境变量 `TONGUE_APPCODE / TONGUE_DIAGNOSE_URL / IMG_HOST_*` 读取 |

> 请务必确认：**提交前再全局搜索一遍 `ApiKey`、`APPCODE`、`passwd`、形如 `xxxx:xxxx` 的密钥串等关键词，确保无遗漏。**

## 四、已排除的无关/不宜提交文件

以下文件不进入软著材料（与"源程序"无关或涉个人数据）：

- `.venv/`、`__pycache__/`、`*.pyc`：运行环境与缓存，非源代码
- `static/uploads/**`：用户上传的舌诊照片等个人数据，**绝不可**提交
- `static/images/**`、`static/js/echarts.min.js`、`static/js/marked.min.js`：图片素材与第三方开源库（非原创代码，不纳入源程序；如确实需要可另行说明）

## 五、软著登记提交要点

1. **软件名称**：按"软件名称 + 版本号（V1.0）"填写，与各子目录名一致。
2. **著作权人**：填写著作权人（单位/个人）全称。文档封面已留 `××××××` 占位，**提交前请替换为实际名称**。
3. **开发完成日期 / 首次发表日期**：说明书封面留占位，请据实填写。
4. **源程序**：中国版权保护中心要求提交"源程序前、后各连续 30 页，共 60 页，每页不少于 50 行；不足 60 页全部提交"。本软件源程序已超过 60 页规模，建议按上述规则从 `源程序/` 目录或合并版 `..._源程序.docx` 中截取前 30 页与后 30 页提交。
5. **说明书**：`说明书/` 下的《软件使用说明书》《软件设计说明书》即可作为登记文档提交，已按 A4、标准标题层级排版。
6. **在线申请**：登录中国版权保护中心官网 → 软件著作权登记 → 填写申请表、上传源程序与文档、缴费、邮寄/电子递交。
